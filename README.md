# 给任何人讲清楚 · Human-Readable

一个 DeepSeek Harness 桌面版插件：**把输入框里那句只有你自己懂的话，结合当前对话上下文，改写成任何人都听得懂、能直接照做的版本。**

它解决的不是「提示词不够专业」，而是「你没把自己脑子里的隐含信息写出来」。

> 判断标准只有一条：把改写后的话念给十个陌生人（小孩、老人、外行）听，只要有一个人要问「什么意思」，就算失败。

---

## 它长什么样

输入框右下角、发送键左边有一枚星光按钮：

1. 写下你想说的话，哪怕只有「继续」「可以了」这种半句；
2. 点一下按钮（或按快捷键）；
3. 输入框里的内容**直接变成**改写后的版本，你可以在原地改、或直接发送。

没有确认弹窗、没有撤销条——不满意就清空重写。

## 安装

需要 DeepSeek Harness 桌面版（本机 profile），并具备插件管理能力。

```text
plugin_manager  action=install_bundle  target=<本仓库的绝对路径>
```

插件是纯 JavaScript，无构建步骤、无依赖安装、无外部 API Key：

- Host 半：`host.js`，注册一条本机 HTTP 路由，读会话上下文并调用当前会话的模型；
- Client 半：`client.js`，往输入框工具行注入按钮，并把结果写回草稿。

## 设置

设置 → 给任何人讲清楚：

| 项 | 范围 | 默认 |
|---|---|---|
| 上下文轮数 | 0–20 | 6 |
| 上下文 token 上限 | 200–8000 | 3000 |
| 快捷键 | 任意含 Ctrl / Alt / Cmd 的组合 | `Alt+H` |
| 模型 | 固定跟随当前会话 | — |

**轮数和 token 是两个闸门，先到者为准**：轮数管「最多看几轮」，token 管「最多占多少体积」，谁先触发就停在哪里。实际使用中助手回复通常几百 token，所以 token 上限往往先起作用，轮数更多是防止「短消息刷屏」。

界面文案跟随 Harness 的语言设置，没有独立的语言开关。

## 已知限制

- **只跟随当前会话的模型**：不支持单独指定第三方模型。实测把慢模型（如带思考链的 gemini）接进来单次要 9 秒以上，与「一键、2 秒内出结果」的产品前提冲突，因此不做。
- **8 秒硬超时**：超时会明确告诉你「模型太慢」，不会静默失败。
- **要快**：deepseek-flash 实测 20 次，中位 1018ms、最慢 1906ms，全部进 2 秒。
- **只改表达，不改语义**：不会替你新增需求，也不编造上下文里没有的事实。
- 上下文只取最近若干轮，更早的指代会补不全——这是为速度做的取舍。
- 仅支持 Harness 桌面版（Web GUI），不做 Chrome 扩展。


## 设计取舍

- **人类可读优先**：输出是大白话，不是 `[ROLE]` / `[CONSTRAINT]` 那种标签堆砌。
- **上下文消解指代**：把「这个 / 那个 / 上面那段」换成具体对象。
- **失败不丢稿**：任何错误都不会动你输入框里的原文。
- **界面服从宿主**：按钮是 ghost 控件，错误用小气泡，不另造一套视觉语言。
